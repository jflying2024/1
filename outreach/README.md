# Zhebao Electrical — Lead Generation & Outreach Kit

Compliant B2B prospecting + outreach materials for finding overseas customers and
sending cold outreach (开发信 / WhatsApp) **without** bulk scraping or spam.

## Files
- `ICP.md` — Ideal Customer Profiles, priority markets, where to find buyers, and
  compliance guardrails (protect the brand & the WhatsApp number).
- `outreach_templates.md` — Cold-email + WhatsApp first-message templates, segmented
  by buyer type (distributor / EPC / panel builder / industrial end-user) + follow-ups.
- `prospects.csv` — A starter list of real target companies across 6 Tier-1 markets
  (UAE, Saudi Arabia, Egypt, Nigeria, Vietnam, Indonesia), with the contact details
  **each company publishes itself** for inbound sales, plus the source and a fit note.

## How to use
1. Open `prospects.csv`, filter by `icp_segment` / `country`.
2. For each row, open the `website` and confirm fit + grab the current sales email.
3. Pick the matching template in `outreach_templates.md`, personalize the first line.
4. Send **email first**; use WhatsApp only where the company publishes a number, via a
   **WhatsApp Business** account (official API for any volume).
5. Log replies; expand the markets/segments that respond.

## Compliance (read before sending)
- `prospects.csv` contains only **publicly self-published business contacts** — no
  scraped private numbers, no purchased lists.
- Do **not** mass-blast identical messages or auto-dial WhatsApp — accounts get banned
  and the brand gets flagged. Personalize and send in small batches.
- Every first message must identify Zhebao, be relevant, and offer an easy opt-out.
- Respect each destination country's privacy / anti-spam law (GDPR-style consent in
  many markets).

## Disclaimer
Contact details were read from public web sources on the date in the `verified_date`
column and can change or become stale. Re-verify each contact on the company's own
website before reaching out, and honor any opt-out / do-not-contact request.
